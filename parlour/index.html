Every board is built by flipping a solved one, so a solution always exists. Par is the number of flips it took to scramble — beat it and you found a shorter route.

Loop

Tap an edge once for a line, twice for a cross, three times to clear it. The cross means “I have decided nothing goes here” — you never need it, but it is how you stop re-checking the same edge. A number dims when its four sides match it. Every board is drawn as a real loop first and the numbers read off it, so an answer always exists, and clues are then stripped one at a time and put back if the board ever gains a second answer. There is exactly one.

Bridges

Tap one island, then another. Tapping the same pair again makes it a double bridge, and a third time removes it. Bridges only run straight up, down, left or right, they cannot cross, and an island goes lime when it has exactly its number of bridge ends. The puzzle is finished when every island is lime and the whole thing is one connected group — two tidy separate clusters is the near miss to watch for. Built by planting islands and running bridges outwards, so it is connected by construction; boards with more than one answer are thrown away.

Kakuro

Tap a square, then a digit. The number above the diagonal is the total going across; the one below is the total going down. Digits are one to nine and none may repeat inside a run — that rule is what makes it solvable by reasoning rather than by trying every sum. A run of two adding to seventeen is eight and nine and can be nothing else. A digit turns red where it repeats in its row or column. Stiff is the same size as Middling but with longer runs; 7×7 is beyond what this generator can produce with a single guaranteed answer, and a smaller board that is certainly unique beats a bigger one that might not be.
